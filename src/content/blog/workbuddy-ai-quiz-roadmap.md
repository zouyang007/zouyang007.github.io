## 阶段：入门 12 个主题 · 初级

> 以概念辨析为主，只配一点场景应用，先建立整体图景

### AI 入门概念 12

#### 01. AI、ML、DL、LLM 的关系与边界

**难度：** 初级

**出题锚点**

- 包含关系：AI ⊃ 机器学习 ⊃ 深度学习，大语言模型是深度学习里的一类模型
- 机器学习的本质是「从数据里拟合规律」，而不是人工写规则
- 判别式模型回答「这是什么」，生成式模型回答「接着该是什么」
- 大模型不是新范式，是同一套方法在规模上的跃变

**易错点**

- 把大语言模型等同于全部人工智能
- 以为参数越多效果一定越好

#### 02. 四种学习范式：监督、无监督、自监督、强化学习

**难度：** 初级

**出题锚点**

- 监督学习：有标签，学「输入 → 输出」的映射
- 无监督学习：没标签，找数据内部结构（聚类、降维）
- 自监督学习：自己从数据里造标签（预测下一个词、掩码填空）
- 强化学习：没有标准答案，靠奖励信号试错
- 大模型预训练属于自监督学习，不是监督学习

**易错点**

- 以为「预训练」是监督学习
- 混淆自监督与无监督

#### 03. 训练集、验证集、测试集与泛化

**难度：** 初级

**出题锚点**

- 三套数据分工不同：训练集用来拟合、验证集用来调参、测试集只做最终评估
- 测试集原则上只能用一次，反复用它就等于偷偷调参
- 泛化能力 = 在没见过的数据上表现好，这才是模型真正有用的标志
- 数据泄漏：训练数据里混进了测试信息，分数会虚高

**易错点**

- 用测试集反复调超参数
- 把训练集上的高准确率当成模型好

#### 04. 损失函数的直觉：训练到底在优化什么

**难度：** 初级

**出题锚点**

- 损失 = 预测与真实目标的差距，训练就是想办法把这个差距压小
- 分类任务常用交叉熵，回归任务常用均方误差
- 损失下降不等于效果变好——可能只是开始过拟合了
- 损失和评价指标不是一回事：损失要可导才能优化，指标要贴近业务才能决策

**易错点**

- 认为损失越低模型一定越好
- 把损失直接当业务指标看

#### 05. 过拟合与欠拟合

**难度：** 初级

**出题锚点**

- 欠拟合：模型太简单，连训练集都学不好
- 过拟合：把噪声也记住了，训练集很好但没见过的新数据很差
- 判定方法：比较训练与验证两条曲线的走势，看它们何时分叉
- 常见对策：加数据、加正则化、早停、降低模型复杂度

**易错点**

- 把训练集表现当成模型能力
- 看到验证集波动就立刻改模型

#### 06. 神经网络的最小单元：神经元与感知机

**难度：** 初级

**出题锚点**

- 一个神经元做三件事：加权求和、加偏置、过激活函数
- 单个感知机只能做线性划分，连简单的异或问题都解决不了
- 多层堆叠 + 非线性激活，才能表达复杂边界
- 「深度」指的就是这种层层堆叠

**易错点**

- 以为单个神经元就能解决任意分类问题
- 觉得层数多没有代价

#### 07. 前向传播：数据怎么流过网络

**难度：** 初级

**出题锚点**

- 前向传播 = 数据从输入层逐层变换到输出层，得到预测值
- 每一层做的事本质相同：一次线性变换 + 一次非线性激活
- 前向算预测、反向算梯度，两者是一对搭档
- 推理时只跑前向，不跑反向，所以推理比训练便宜得多

**易错点**

- 混淆前向传播与反向传播
- 以为推理也要更新参数

#### 08. Token 与上下文窗口

**难度：** 初级

**出题锚点**

- token 是模型处理的最小单位，不等于字、也不等于词
- 中文里一个汉字通常对应 1～2 个 token，英文一个词可能被拆成多个 token
- 上下文窗口 = 模型一次最多能看多少 token，含输入和输出
- 成本与延迟大致随 token 数增长，长上下文不是免费的

**易错点**

- 把字数直接当成 token 数去估算成本
- 忽略长上下文带来的费用与延迟

#### 09. 参数量、算力、显存：三个常被混淆的概念

**难度：** 初级

**出题锚点**

- 参数量决定模型容量（能装多少知识）
- 算力决定训练/推理速度（跑多快）
- 显存决定模型能不能跑起来（装不装得下）
- 推理显存 ≈ 参数量 × 每个参数的字节数，与精度直接相关

**易错点**

- 把参数量和显存需求画等号却忽略精度设置
- 以为参数量大就必须用多卡才能推理

#### 10. 预训练、微调、推理：三个阶段各做什么

**难度：** 初级

**出题锚点**

- 预训练：海量文本上学通用语言能力，成本最高，通常只有大厂做
- 微调：用少量领域数据把通用模型调整到具体任务上
- 推理：只做前向计算，不改变任何参数
- 三者在数据量、算力、耗时上差好几个数量级

**易错点**

- 以为微调也需要预训练那个量级的数据
- 把「训练一个新模型」当成解决问题的默认选项

#### 11. 幻觉：模型为什么会一本正经地编

**难度：** 初级

**出题锚点**

- 幻觉 = 生成流畅、听起来合理但并不真实的内容
- 根源在于模型本质是概率生成，优化目标是「像」而不是「真」
- 加重因素：训练知识过时、问题超出范围、提示本身带误导
- 缓解手段：检索增强、要求给引用、多路径自检、允许模型说「不知道」

**易错点**

- 以为幻觉是单纯的程序缺陷，调大模型就能消除
- 不加验证就采信模型输出的事实性内容

#### 12. 怎么判断一个模型好不好

**难度：** 初级

**出题锚点**

- 准确率在类别不均衡时会骗人，要配合精确率、召回率、F1 一起看
- 生成任务没有唯一标准答案，评估本身比分类难得多
- 公开榜单存在污染与过拟合，排名不能当绝对结论
- 最可靠的做法：拿你自己的真实数据、按你的业务标准去测

**易错点**

- 只看单一指标就下结论
- 把公开榜单排名当作最终答案

### 数学与信息论 3

#### 13. 矩阵与线性变换

**难度：** 中级

**出题锚点**

- 矩阵乘法是线性映射的复合而非逐元素运算
- 秩刻画输出空间的维度，低秩意味着信息压缩
- 特征值描述变换下的不变方向
- SVD 是理解低秩近似与降维的通用工具

**易错点**

- 把矩阵乘法理解成逐元素相乘

#### 18. 熵、交叉熵与 KL 散度

**难度：** 中级

**出题锚点**

- 熵 = 分布自身的不确定度；交叉熵 = 熵 + KL(真实||预测)
- 最小化交叉熵等价于最小化 KL 散度
- KL 散度不对称，不是距离度量
- one-hot 标签下交叉熵退化为 -log(p_正确类)

**易错点**

- 认为 KL 散度满足对称性
- 混淆交叉熵与困惑度的关系

#### 20. 梯度下降家族

**难度：** 中级

**出题锚点**

- SGD / Momentum / RMSProp / Adam 的递进关系
- Adam = 一阶动量 + 二阶动量（自适应步长）
- 学习率通常是影响最大的单一超参
- Adam 收敛快但不必然泛化更好

**易错点**

- 认为 Adam 一定优于 SGD
- 把 AdamW 与 Adam 当作同一个东西

### 神经网络基础 6

#### 14. 激活函数

**难度：** 初级

**出题锚点**

- 非线性的来源，没有它多层网络等价于单层线性变换
- ReLU 缓解梯度消失但有死亡神经元问题
- GELU/SiLU 更平滑，是现代 Transformer 的默认选择
- Sigmoid/Tanh 在深层网络中易饱和

**易错点**

- 认为激活函数对性能影响很小

#### 19. 反向传播

**难度：** 中级

**出题锚点**

- 本质是链式法则在计算图上的高效实现
- 前向保存中间激活，反向逐层回传梯度
- 梯度在汇合节点处累加
- 计算成本约等于两次前向传播

**易错点**

- 忘记清零梯度导致梯度累积
- 认为反向传播是一种优化算法

#### 21. 参数初始化

**难度：** 中级

**出题锚点**

- Xavier 适合 tanh 系，He 初始化适合 ReLU 系
- 目标是让各层激活方差保持稳定
- 初始化不当会导致梯度爆炸或消失
- 残差结构需要按层数缩放初始方差

**易错点**

- 全零初始化（导致对称性无法打破）

#### 22. 正则化与过拟合

**难度：** 中级

**出题锚点**

- Dropout 训练时随机置零、推理时缩放
- 权重衰减压制大权重，AdamW 将其与自适应步长解耦
- 早停是最廉价的正则化手段
- 数据增强与更多数据通常优于任何正则化技巧

**易错点**

- 认为 Adam 下的 weight decay 等价于 L2

#### 23. 学习率调度与 warmup

**难度：** 中级

**出题锚点**

- warmup 让早期不稳定的梯度不破坏参数
- 余弦退火是当下最常见的衰减策略
- 峰值学习率与 batch size 相关
- 学习率过大表现为 loss 震荡甚至发散

**易错点**

- 在深层 Transformer 上直接使用恒定大学习率

#### 24. 归一化层

**难度：** 中级

**出题锚点**

- BatchNorm 沿 batch 维统计，依赖 batch 大小
- LayerNorm 沿特征维统计，与 batch 无关
- 变长序列场景下 LN 更适用
- 归一化位置与残差结构的组合影响训练稳定性

**易错点**

- 在小 batch 或变长序列上照搬 BatchNorm

### RAG 与检索 1

#### 15. 文本向量化

**难度：** 初级

**出题锚点**

- 双塔结构分别编码查询与文档，可离线建索引
- 余弦相似度与内积的关系（归一化后等价）
- 向量维度与效果、存储成本的权衡
- 领域数据上需要对比学习微调才能拉开区分度

**易错点**

- 直接用通用 embedding 处理强专业语料却不评估召回

### 预训练 1

#### 16. 分词与 BPE

**难度：** 初级

**出题锚点**

- 子词粒度在词表大小与序列长度之间取平衡
- BPE 从字符对频率出发自底向上合并
- 词表越大序列越短，但 embedding 参数量越大
- 中文常按字/子词混合切分，需要专门的词表设计

**易错点**

- 认为分词对模型效果无影响
- 忽略 OOV 与空格处理带来的偏差

### 微调与对齐 1

#### 17. Prompt 工程

**难度：** 初级

**出题锚点**

- 零样本 / 少样本 / 思维链的适用边界
- 指令要具体、约束要可验证、输出格式要显式约定
- 示例的质量与一致性比数量更重要
- 结构化输出需配合 schema 校验与失败重试

**易错点**

- 靠堆砌形容词提升效果
- 指令之间互相冲突却不自知

## 阶段：核心 14 个主题 · 中级

> 原理与推导为主，开始出现代码题

### Transformer 6

#### 25. 自注意力机制

**难度：** 中级

**出题锚点**

- Q/K/V 的角色分工：Q 与 K 算权重，V 是被加权取出的内容
- 缩放因子 1/sqrt(d_k) 控制点积方差、避免 softmax 饱和
- 复杂度 O(n^2 d)，随序列长度平方增长
- 权重是 softmax 归一化后的凸组合，本质是软性的加权平均

**易错点**

- 把注意力权重当作模型的可解释性证据
- 误以为 Q、K、V 来自三个不同的输入

#### 26. 多头注意力

**难度：** 中级

**出题锚点**

- 把 d_model 拆成 h 个子空间并行做注意力，再拼接投影
- 总计算量与单头大致持平，但表达能力更强
- 不同头可捕捉不同模式（局部、句法、共指）
- 常见约束 d_k = d_model / h

**易错点**

- 认为多头会让参数量成倍增长

#### 27. 位置编码

**难度：** 中级

**出题锚点**

- 自注意力本身是置换不变的，必须显式注入位置信息
- 绝对位置编码 vs 相对位置编码的取舍
- RoPE 通过旋转矩阵让点积自然携带相对距离
- 外推性决定模型能否处理超出训练长度的上下文

**易错点**

- 认为位置编码只是个无足轻重的细节

#### 28. 残差连接与归一化位置

**难度：** 中级

**出题锚点**

- 残差连接为梯度提供恒等通路，是深层可训练的前提
- Post-LN 需要 warmup，Pre-LN 训练更稳定
- 归一化放在子层之前还是之后影响收敛行为
- RMSNorm 去掉均值中心化以节省计算

**易错点**

- 以为残差连接只是为了加深网络

#### 29. 三种架构选型

**难度：** 中级

**出题锚点**

- Encoder-only 适合理解类任务（分类、抽取）
- Decoder-only 适合生成与通用对话，扩展性最好
- Encoder-Decoder 适合输入输出都长的转换类任务
- 架构选择应与任务形态匹配而非跟风

**易错点**

- 用生成模型做分类却不评估成本

#### 38. KV Cache

**难度：** 高级

**出题锚点**

- 自回归解码时历史 token 的 K/V 可复用，避免重复计算
- 缓存显存随 batch x 层数 x 序列长度线性增长
- MQA/GQA 通过共享 K/V 头压缩缓存
- 缓存是吞吐与显存的主要矛盾来源

**易错点**

- 忽略长上下文场景下 KV Cache 的显存占用

### 预训练 2

#### 30. 预训练目标：MLM 与 CLM

**难度：** 中级

**出题锚点**

- MLM 双向可见、擅长理解任务；CLM 单向自回归、擅长生成
- MLM 的 [MASK] 造成预训练与微调不一致
- CLM 训练效率高，可复用全部 token 的监督信号
- 解码器架构在规模上被验证更易扩展

**易错点**

- 认为双向一定比单向强

#### 31. 预训练数据工程

**难度：** 中级

**出题锚点**

- 去重（尤其跨语料近似去重）对效果影响巨大
- 质量过滤常用启发式规则 + 分类器打分
- 数据配比决定模型的能力分布
- 基准污染会虚高评测成绩

**易错点**

- 认为数据越多越好而忽略清洗与配比

### 微调与对齐 3

#### 32. 思维链与推理

**难度：** 中级

**出题锚点**

- 显式中间步骤能显著提升多步推理准确率
- CoT 对简单事实题收益有限甚至有害
- 自洽性采样：多次采样取多数答案
- 推理型模型把思考过程内化到训练阶段

**易错点**

- 在所有任务上无脑加一句「请一步步思考」

#### 33. 指令微调 SFT

**难度：** 初级

**出题锚点**

- 让小模型具备遵循指令的能力，成本远低于继续预训练
- 数据质量与格式一致性比数据量更关键
- 只在回答部分计算 loss 是常见做法
- 存在灾难性遗忘风险，需混入通用数据

**易错点**

- 认为 SFT 可以注入新知识

#### 34. LoRA 与 QLoRA

**难度：** 中级

**出题锚点**

- 用低秩矩阵分解近似权重更新，冻结原权重
- 秩 r 与缩放 alpha 控制容量与强度
- QLoRA = 4bit 量化基座 + LoRA + 分页优化器
- 可在消费级显卡上微调大模型

**易错点**

- 认为 LoRA 效果一定不如全量微调

### RAG 与检索 2

#### 35. 切分策略

**难度：** 中级

**出题锚点**

- 固定长度切分简单但会切断语义单元
- 语义/结构切分（按标题、段落）召回质量更高
- 相邻块重叠可缓解边界信息丢失
- 小块检索、大块生成的父子块策略

**易错点**

- 块太大会稀释语义，太小会丢上下文

#### 36. 混合检索与重排

**难度：** 中级

**出题锚点**

- BM25 擅长关键词与稀有词，向量擅长语义近似
- RRF 等融合策略合并多路召回结果
- Cross-encoder 重排精度高但无法离线预计算
- 典型两段式：宽松召回 + 精细重排

**易错点**

- 只用向量检索处理含大量专有名词的语料

### 评估与安全 1

#### 37. 生成任务评估指标

**难度：** 中级

**出题锚点**

- BLEU/ROUGE 基于 n-gram 重叠，与人类判断相关性有限
- 语义相似度指标对改写更鲁棒
- 任务相关指标（事实性、格式合规）往往比通用指标更有用
- 任何自动指标都需人工抽检校准

**易错点**

- 用单一 BLEU 分数作为上线依据

## 阶段：应用 12 个主题 · 中级

> 偏工程选型与方案设计，代码题常态化

### 推理与部署 4

#### 39. 显存估算

**难度：** 中级

**出题锚点**

- 推理显存 = 权重 + KV Cache + 激活开销
- 训练显存还要加上梯度与优化器状态（Adam 约 2 倍权重）
- 量化主要压缩权重，不解决 KV Cache 膨胀
- 显存公式是判断能否上线的第一道门槛

**易错点**

- 只用参数量估算显存而忽略 KV Cache

#### 40. 量化

**难度：** 中级

**出题锚点**

- INT8/INT4 压缩权重，降低显存与带宽压力
- 训练后量化 PTQ vs 量化感知训练 QAT
- 误差主要来自离群值，需分组或混合精度处理
- 推理速度提升取决于是否被访存瓶颈限制

**易错点**

- 认为量化只是省显存、不影响质量

#### 41. 批处理与吞吐

**难度：** 中级

**出题锚点**

- 静态批处理受最长序列拖累，连续批处理动态补位
- TTFT 与 TPOT 分别刻画首字延迟与出字速度
- PagedAttention 用分页管理 KV Cache 减少碎片
- 吞吐与延迟是此消彼长的取舍

**易错点**

- 只看平均延迟不看长尾 P99

#### 48. 知识蒸馏

**难度：** 中级

**出题锚点**

- 软标签携带类间相似性信息，比硬标签信息量更大
- 温度参数调节软标签的平滑程度
- 蒸馏可与量化、剪枝叠加使用
- 教师模型的错误也会被一并继承

**易错点**

- 认为蒸馏只是简单地用大模型数据做微调

### Agent 4

#### 42. 工具调用与 Function Calling

**难度：** 中级

**出题锚点**

- 用 JSON Schema 描述工具签名，模型输出结构化调用
- 多轮循环：模型决策 -> 执行 -> 结果回灌
- 必须处理参数错误、超时与幂等性问题
- 工具描述质量直接决定调用准确率

**易错点**

- 工具粒度过细导致决策空间爆炸

#### 43. ReAct 与规划

**难度：** 中级

**出题锚点**

- 思考-行动-观察循环，把推理与工具使用交织
- 能用确定性工作流解决的不要上 Agent
- 循环需要步数上限与失败兜底
- 规划粒度太细会放大误差累积

**易错点**

- 为简单的线性流程引入完整 Agent 框架

#### 44. MCP 与上下文协议

**难度：** 初级

**出题锚点**

- 把工具与数据源标准化为可插拔的服务端
- 客户端统一管理能力发现与授权
- 与 Function Calling 是层次关系而非替代关系
- 鉴权与权限边界是落地时的核心问题

**易错点**

- 把 MCP 当成又一个工具调用格式

#### 49. Agent 记忆系统

**难度：** 高级

**出题锚点**

- 短期记忆=上下文窗口，长期记忆=外部存储+检索
- 写入策略（记什么）比检索策略更容易出错
- 摘要压缩会丢失细节，需要分层保留
- 记忆污染与过期信息需要清理机制

**易错点**

- 把所有对话原样写入长期记忆导致噪声累积

### RAG 与检索 1

#### 45. RAG 评估

**难度：** 高级

**出题锚点**

- 要拆开评估检索（召回率/命中率）与生成（忠实度/相关性）
- 忠实度衡量答案是否只依据检索内容
- 端到端指标无法定位瓶颈在检索还是生成
- 需要构建带标注答案的评测集

**易错点**

- 只看端到端得分，无法定位问题环节

### 评估与安全 2

#### 46. LLM-as-Judge

**难度：** 高级

**出题锚点**

- 用强模型给输出打分或两两对比
- 已知偏差：位置偏好、长度偏好、自我偏好
- 缓解手段：交换位置、评分标准显式化、多次采样
- 必须用人工标注子集校准

**易错点**

- 用同一模型既生成又评估而不做偏差校正

#### 47. 对齐与安全

**难度：** 中级

**出题锚点**

- 提示注入把不可信内容当指令执行，是 RAG/Agent 的头号风险
- 越狱利用角色扮演与场景包装绕过约束
- 防御要多层：输入过滤、权限最小化、输出校验
- 不可信内容与指令必须在通道上隔离

**易错点**

- 只在 prompt 里加一句「不要做坏事」当作防护

### 多模态 1

#### 50. CLIP 与对比学习

**难度：** 中级

**出题锚点**

- 图文双塔在同一空间对齐，用 InfoNCE 拉近正样本
- batch 内其他样本充当负样本
- 训练后可做零样本分类：与类别文本比相似度
- 对细粒度与计数类任务能力有限

**易错点**

- 认为 CLIP 可以做精细的视觉定位

## 阶段：深入 11 个主题 · 高级

> 推导、论文判读与开放设计题，检验综合能力

### Transformer 1

#### 51. 高效注意力

**难度：** 高级

**出题锚点**

- FlashAttention 是 IO 感知的精确算法，不近似数学结果
- 分块计算 + 在线 softmax，避免物化 n x n 注意力矩阵
- 瓶颈常是显存带宽而非浮点算力
- 与稀疏/线性注意力是不同层面的优化

**易错点**

- 认为 FlashAttention 是通过近似加速的

### 推理与部署 1

#### 52. 投机解码

**难度：** 高级

**出题锚点**

- 小模型草拟多个 token，大模型一次并行验证
- 加速比取决于草稿的接受率
- 输出分布与原始模型严格一致（正确实现下）
- 草稿模型与目标模型分布越接近收益越大

**易错点**

- 以为投机解码会牺牲输出质量

### 微调与对齐 2

#### 53. DPO 与偏好优化

**难度：** 高级

**出题锚点**

- 直接用偏好对优化策略，无需显式奖励模型
- 目标函数隐含了 KL 约束，防止偏离基座过远
- 比 RLHF 稳定且实现简单，但依赖偏好数据质量
- 与在线迭代采样结合效果更好

**易错点**

- 在没有偏好标注的情况下硬套 DPO

#### 54. RLHF

**难度：** 高级

**出题锚点**

- 流程：SFT -> 奖励模型 -> PPO 优化
- PPO 阶段同时持有策略、参考、奖励、价值四个模型
- 奖励黑客：模型学会讨好奖励模型而非真实目标
- KL 惩罚用于约束策略不要偏离参考模型

**易错点**

- 忽略奖励模型的过优化问题

### 数学与信息论 1

#### 55. 困惑度与语言模型

**难度：** 高级

**出题锚点**

- 困惑度 = 平均交叉熵的指数
- 可理解为模型在每一步的平均候选困惑程度
- 困惑度受分词影响，跨词表不可直接比较
- 困惑度低不保证下游任务表现好

**易错点**

- 跨不同分词器比较困惑度数值

### Agent 1

#### 56. 多智能体协作

**难度：** 高级

**出题锚点**

- 分工模式：流水线、评审、辩论
- 通信成本随角色数快速上升
- 多数场景下单 Agent + 好工具优于多 Agent
- 需要明确的终止条件与结果收敛机制

**易错点**

- 为了架构好看而引入多智能体

### 评估与安全 1

#### 57. 基准污染

**难度：** 高级

**出题锚点**

- 测试集泄漏进训练语料会虚高分数
- 检测手段：n-gram 重叠、扰动鲁棒性、时间切分
- 动态更新的基准比静态基准更可信
- 污染是评测结论可信度的第一威胁

**易错点**

- 直接信任公开榜单分数而不看污染审计

### 预训练 2

#### 58. 缩放定律

**难度：** 高级

**出题锚点**

- loss 随参数量、数据量、算力呈幂律下降
- Chinchilla 给出算力预算下的最优参数-数据配比
- 过度训练小模型以降低推理成本是当前主流做法
- 定律用于资源分配决策而非精确预测

**易错点**

- 用缩放定律外推到完全不同架构或数据分布

#### 59. 分布式训练并行策略

**难度：** 高级

**出题锚点**

- 数据并行/张量并行/流水线并行/专家并行的适用场景
- ZeRO 分片优化器状态、梯度与参数以省显存
- 通信量与并行维度的关系决定实际加速比
- 大规模训练是通信-计算重叠的工程问题

**易错点**

- 以为增加卡数就能线性加速

### 多模态 2

#### 60. 视觉语言模型架构

**难度：** 中级

**出题锚点**

- 视觉编码器 + 投影层 + 语言模型三段式
- 投影层把视觉特征映射到语言模型的嵌入空间
- 高分辨率图像需要切片或动态分辨率处理
- 视觉 token 数量直接拉高上下文与算力开销

**易错点**

- 忽略视觉 token 对上下文预算的挤占

#### 61. 扩散模型

**难度：** 高级

**出题锚点**

- 前向逐步加噪，反向学习去噪
- 训练目标简化为预测噪声
- DDIM 等采样器用更少步数近似同样结果
- 潜在扩散在压缩后的潜空间操作以降低算力

**易错点**

- 认为扩散模型的采样步数与质量必然成正比
