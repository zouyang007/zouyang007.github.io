欢迎来到你的新博客。

这里没有复杂的后台。每一篇文章都是一个普通的 Markdown 文件：标题和发布日期放在最上方，正文写在下面。文件跟随 Git 仓库一起保存，因此你始终拥有自己的内容。

## 先写清楚，再追求完整

第一篇文章不需要宏大的主题。你可以从最近解决的一个问题、读完的一本书，或者一段想长期保留的经验开始。

> 能够持续发布的朴素系统，比永远停留在设计阶段的完美系统更有价值。

发布前，运行一次本地检查；确认页面正常后提交并推送。几分钟后，GitHub Pages 就会自动更新网站。

## 替换这篇示例

复制文末 README 中的文章模板，新建一个英文短文件名，然后删除这几篇示例文章。永久链接一旦公开，尽量不要再修改文件名。
