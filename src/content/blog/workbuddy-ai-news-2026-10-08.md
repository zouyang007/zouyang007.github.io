## 二、详情

### 1. **OpenAI 把 GPT-6 推给 12 亿用户：回答从「文字」变成「界面」**
OpenAI 于 **10/7** 起在 ChatGPT 的 Chat 标签页面向 **Plus / Pro / Business / Enterprise** 推送 GPT-6，**Free 与 Go 档于 10/8** 跟进；付费档由 **GPT-6 Sol** 驱动、免费档由 **GPT-6 Luna** 驱动。核心新功能 **Intelligent UI** 让回答按问题类型自动混排文本、图形、可点击按钮、表单、图表，甚至现场生成可交互的小工具（账单分账器、退休储蓄计算器、可在对话里玩的复古游戏）；OpenAI 称这套界面建立在**原生可流式组件库 + 编译器**之上，界面随模型生成逐步呈现，无需等整段回答结束。效率方面，GPT-6 可在**仍在推理时开始输出**，官方内部数据显示网页搜索场景 **GPT-6 Instant 平均提前 44% 开始作答**，日常智能体任务上 **GPT-6 Extra High** 的起答速度与 GPT-5.6 Medium 相当、总得分高于 GPT-5.6 Extra High。安全上，系统卡称两款模型均被列为网络安全与生物化学领域「高能力」级别、但未达到「AI 自我改进」高能力门槛；指令层级提示词注入防护率分别为 **99.99% 与 99.79%**，间接提示词注入为 **97.13% 与 95.80%**，多轮越狱防御成功率均高于 GPT-5.6 Sol。官方明确说明**驱动 Work 与 Codex 的模型不在本次调整范围**。
**影响点评**：这条真正改变的不是模型能力，而是**「输出格式的默认值」**——当模型自己决定该给文字还是给界面，「一次性生成的即用小工具」会直接冲击大量单一功能 SaaS 的存在理由；同时也意味着 **UI 组件库正成为前沿实验室的新护城河**（Google 早在 5 月已在 Gemini 上线类似的 Neural Expressive，如今 OpenAI 在消费级规模上给出参考实现）。
[来源：OpenAI 官方博客（openai.com）、OpenAI 系统卡（deploymentsafety.openai.com）、The Decoder、Unite.AI、Splitfeed、腾讯新闻、IT时代网]
**注**：「12 亿」为每周使用 ChatGPT 的用户数（OpenAI 官方口径）；「44%」为厂商内部评测数据，未经第三方复现。

### 2. **Claude Haiku 5.5：小模型价格战被推到 $0.10/$0.50**
Anthropic 于 **10/7（周三）**发布 **Claude Haiku 5.5**（模型 ID `claude-haiku-5-5`），称其为迄今**最快、最便宜、能力最强**的 Haiku，也是**首款支持可调 effort 档位**的 Haiku。定价：**≤10 万 Token 的请求，输入 $0.10 / 输出 $0.50 每百万 Token**（Haiku 4.5 为 $1/$5，降幅 90%），**超过 10 万 Token 则降 50%**；因新分词器使单位文本消耗 token 略多，Anthropic 给出**平均降本约 75%** 的口径。缓存读取 $0.01（≤10 万）/$0.05，缓存写入 $0.125/$0.625。基准成绩（均为厂商口径）：**OSWorld 2.1 离线子集 72.4%**（Haiku 4.5 为 15.7%、同门 Sonnet 5.5 为 70.6%、OpenAI GPT-6 Luna 为 48.9%）、**Terminal-Bench 4.0 39.2%**（Haiku 4.5 为 0%）、**GDPval-AA v2.1 1620 分**（Haiku 4.5 为 735、Luna 为 1437）、Humanity's Last Exam 无工具 45.9%。同步下调 **Sonnet 5.5 缓存读取价**（$0.20 → $0.10/百万 Token），Anthropic 称可让多数智能体任务成本再降约 **20%**；本周起 Max 5x / Max 20x / Team 订阅用户另获每月 **$100 / $200 / 最高 $500（团队池化）**的 API 额度。模型已在 Claude 平台、AWS、Google Cloud、Azure 上线。
**影响点评**：**$0.10/$0.50 与 OpenAI 的 GPT-6 Luna 完全同价**——小型模型的价格战已经从「比便宜」进入「同价拼能力、拼定位」阶段。更值得注意的是 Anthropic 把自己的一款小模型**明确摆到 Sonnet 5.5 的分数之上**（OSWorld 72.4% vs 70.6%）再用 effort 档位做区隔：它实际卖的不是「更强的模型」，而是**「让 Agent 的每一步都便宜到可以不计成本」**，这与其 IPO 前压低单位任务成本、做大调用量的财务动机高度一致。
[来源：Anthropic 官方（anthropic.com/claude-haiku-5-5）、Decrypt、clauday、每日经济新闻、钛媒体、网易科技、CNMO]
**注**：OSWorld 2.1 为部分给分制；Anthropic 自己的图表仍显示 Sonnet 5.5 在困难 Agent 层级更强，「小模型超旗舰」仅限特定基准。

### 4. **谷歌 SynthID 检测器向所有人开放，并首次跨公司识别水印**
Google DeepMind 于 **10/7** 宣布，此前仅向记者、研究人员与媒体专业人士开放（需排队）的 **SynthID Detector** 转为**全球英文公开**，任何人可登录（支持 Google、OpenAI、Apple 账号）后在 synthid.com 上传图片、视频或音频，检查其中是否含 SynthID 隐形水印。本次的关键升级是**首次支持合作伙伴的水印**——Google 之外，可识别 **OpenAI、NVIDIA、Kakao** 生成媒体的水印，**Apple 即将加入**。规模数据：自 2023 年 SynthID 上线以来，已应用于**超 1800 亿张图片与视频**、约 **24 万年**音频；Search、Gemini 应用与 Chrome 中的核验功能**每天处理超 100 万次请求**。使用限制：每人每日约 **10 次**检查配额，Google 工程师称限额是为防止有人用反复检测来开发去除水印的工具。
**影响点评**：这是**「跨公司内容溯源层」第一次有了面向普通用户的统一入口**——此前即便 ChatGPT 生成的图片带 SynthID，Google 的检测器也认不出来，只能逐家去查。但必须写清的局限是：**未检出 ≠ 真实**——Meta 使用别的水印技术，大量开源权重模型既不加水印也不带元数据，因此这套工具只能证明「是」，不能证明「不是」；Ars Technica 也指出更可靠的长期方向可能反而是给真实内容做加密签名（如 C2PA）。
[来源：Google 官方博客（The Keyword）、Google DeepMind 官方 X 帖、Ars Technica、Digital Trends、Techgenyz]

### 5. **谷歌与 Unity 联手：Playground 上线，Unity Spark 年底闭测**
**10/7** 谷歌与游戏引擎公司 Unity 宣布战略合作，推出面向下一代互动娱乐的 AI 游戏平台。已有产品是谷歌的实验性平台 **Playground**（playground.google），面向美国 **18 岁以上**用户，任何人都可用自然语言提示**生成与定制可玩游戏、无需编写代码**，支持浏览器在手机与笔记本上游玩、生成分享链接或发布到 Explore 图库、部分品类支持游戏内排行榜与多人对战；创作额度按 Google One 会员等级分层，所有上架游戏都需通过与其社区准则对齐的安全筛查。后续产品 **Unity Spark** 计划**今年晚些时候**在 Playground 上以**闭测**形式推出，提供「专业级机制、高保真 3D 能力与 Unity 运行时」的灵活性，**直连 Unity Asset Store**；Unity 明确说明 Spark 编辑器**仅支持桌面浏览器**、游戏可在桌面与移动端游玩，**上线时不支持下载项目、不支持导出到桌面版 Unity、也不能售卖作品**，计费采用与 AI token 挂钩的积分制（细节未定，含一定免费额度）。Unity CEO **Matt Bromberg** 在博客中主动划清界限：**「这不是 one-shotting……让 AI 复述一款已经存在的游戏，不会让你成为下一个小岛秀夫。」**
**影响点评**：市场反应温和（Unity 股价基本持平、Roblox 跌不足 1%），说明投资者已不像 1 月 **Project Genie** 世界模型原型曝光时那样恐慌；但这条真正值得注意的是**两种路线的分野**——谷歌卖的是「打字出游戏」的**入口级便利**，Unity 卖的却是「不放弃资产商店与引擎运行时」的**专业工作流**。Bloomberg Intelligence 分析师 Nathan Naidu 的判断比较准：这**降低了「AI 让 Unity 核心工具变得多余」的担忧**，中期对 Roblox 的社交优势威胁有限。
[来源：Google 官方博客（The Keyword）、Unity 官方博客与官网、Straits Times（彭博）、GamesBeat、GamesIndustry.biz]

### 7. **Biohub「虚拟生物学计划」扩至 18 亿美元：中美欧之外的第三条生物 AI 路线**
**10/7**，非营利机构 **Biohub**（由马克·扎克伯格与妻子、医师 Priscilla Chan 共同创办）在美国 Redwood City 宣布扩大 **Virtual Biology Initiative**：**Biohub + 美国能源部（DOE）+ 美国国立卫生研究院（NIH）+ 新出资方，合计投入 18 亿美元**的资金、数据、算力与新测量技术，称这是迄今**规模最大的「AI 可用生物数据」协同承诺**。结构上：**DOE 五年投入超 5 亿美元**（实验室测量、建模、算力，属其主导的 Genesis Mission，将动用超算、X 射线/中子散射、冷冻电镜与自治实验室）；**NIH 协调此前超 5 亿美元联邦投入**所形成的生物医学数据集、国家生物医学仓储与知识库，由 Biohub 负责标准化以适配 AI 训练；**Google DeepMind、Isomorphic Labs 与 Meta 合计投入 3 亿美元**。Biohub 今年 4 月已投入 5 亿美元（其中 4 亿用于冷冻电子断层扫描、可成像百万至十亿级细胞的显微技术等新测量工具，1 亿资助外部研究）。目标：让科学家**先在数字环境中做实验**，建立可预测细胞行为的「虚拟细胞」模型；计划**约一年后交付首批数据集**、**五年内建立具备准确预测能力的模型**。数据开放采用「开放科学 + 商业禁运期」模式：出资企业有一段时间的优先使用权，之后公开；政府资助部分无此限制。Biohub 科学主管 **Alex Rives** 称现有细胞数据集规模在数亿级，而准确模型需要数十亿乃至数万亿级数据，并称这项工作「通常要几十年，合作伙伴想压缩到五年」。
**影响点评**：这条是**「生物 AI 的第三条路线」成型**——既不是 OpenAI/Anthropic 式的私营实验室自建能力，也不是欧盟式的资助计划，而是**政府基础设施（DOE 超算 + NIH 数据 + 国家实验室）+ 商业 AI 能力（Meta、DeepMind、Isomorphic）+ 非营利中立运营**的三方拼图。它同时给出了一个可复制的制度答案：用**「商业禁运期」换取私人资本**，以此在不放弃开放科学承诺的前提下解决数据生成的巨额成本；对照来看，Anthropic 已扩建湿实验室、OpenAI Foundation 启动了超 1.25 亿美元的生物医学数据集资助计划，说明「AI for Science 的数据底座」正在成为各家必争之地。

### 8. **Sierra 与 Meta 发布 Personal Agent Protocol：给「个人智能体」定身份与权限**（补记，事件日 10/6）
**10/6**，Sierra 宣布与 **Meta** 及 **Genesys、Instinct、Rocket、Shopify、Stripe、Walmart** 共同开发 **Personal Agent Protocol（PAP）**开放标准，定义个人 AI 智能体如何与企业交互（Meta 的公告另列 **NiCE、Decagon**）。技术要点：基于 **OAuth**；三级访问——**访客（可查库存、退货政策）→ 只读（可看订单历史）→ 写入（可下单/改单）**，授权由用户决定、可执行的边界由企业设定；企业可选择三种对接通道（自家网站页面 / 基于 **MCP、OpenAPI** 的 API / 企业自有智能体），会话**跨渠道延续**（登录前提问与登录后改单视为同一次访问）；对商家**不收取授权费用**。**v0.1 规范计划本月晚些时候发布**，随后举办设计工作坊并提供参考实现；支付、推送通知与更细粒度权限列为**后续扩展**。同日竞争标准是 **Decagon 的 PACT**（基于 Agent2Agent 协议 + OAuth 2.0），Decagon 同时加入 PAP 工作组。Sierra 联合创始人、OpenAI 董事长 **Bret Taylor** 对 CNBC 称「没有这样的标准，就是一片混乱」；Meta Superintelligence Labs 负责人 **David Singleton**（前 Stripe CTO）称在「定义未来个人智能体与企业智能体可以行驶的轨道」。
**影响点评**：**创始阵营里没有 Amazon、OpenAI、Anthropic 才是这条的真正信息量**——Amazon 9 月刚以「未表明自己是智能体」为由屏蔽 Meta 的 Muse，OpenAI 与 Anthropic 亦缺席；而 Stripe 与 Shopify 同时已经参与 Visa 主导的另一套协议，说明**智能体商务的标准之争已在「身份认证层」「支付结算层」同时开打**。企业侧的现实建议是：不要等某一套标准胜出，**现在就把「可授权、可撤销、分档次的权限」设计进面向智能体的接口**，因为 Muse、Dots、Instinct 这类个人智能体进入客服与下单通道已是确定趋势（WSJ 引用数据显示仅 3% 美国成年人信任 AI 智能体代其完成购买）。
